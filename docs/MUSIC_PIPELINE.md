# Music Pipeline

CALMQUEST's music is **composed as code** and rendered offline. This page explains the current state honestly, then how to produce real orchestral renders.

## Current state (what is in the game now)

| Files | What they are | Status |
|---|---|---|
| `assets/music/midi/*.mid` (14 cues) | Multi-track General MIDI scores generated by `tools/music/compose.py` | **MIDI only.** Ready to render. |
| `assets/music/placeholder/*.wav` (14 files) | Loops rendered from the same notes with simple additive synthesis (numpy) | **Synthesized placeholders.** Not orchestral. Labelled as placeholders in the code, the Settings panel and these docs. |
| `assets/ambience/placeholder/*.wav` (8 files) | Wind, highland wind, waves, creek, cave drips, night insects, meadow birds, rain, synthesized from noise and sine tones by `tools/music/ambience.py` | Original synthesized ambience. |

No orchestral library or SoundFont was used. On the development machine there was:
- no MuseScore and no FluidSynth;
- no `.sf2` SoundFont;
- no `ffmpeg` or `oggenc`, so the placeholders are 16-bit WAV, not Ogg Vorbis;
- no `mido` or `pretty_midi`. The script writes Standard MIDI Files itself, using only the standard library plus numpy and scipy.

The music is designed to support a calm atmosphere. No claim is made that it reduces stress or has any therapeutic effect.

## Step 1: compose (MIDI)

```
python tools/music/compose.py --midi-only
```

All musical choices are data at the top of `compose.py`:
- `THEME`, `ANSWER`, `THEME_HIGH`, `CADENCE` (and 6/8 versions): the shared **Lumeria main theme**, written as scale degrees and beats. Every cue reuses these motifs, transposed and re-voiced.
- `CUES`: per cue, the key root, mode (major, Lydian or Mixolydian only), tempo (58-76 BPM; slower for the cottage, caves and sanctuary), beats per bar (6/8 for the coast), an 8-bar progression whose last chord leads back to the first so it loops cleanly, and the parts (instrument, role, octave, velocity).
- `INSTRUMENTS`: General MIDI programs.

| Instrument | GM program |
|---|---|
| Piano | 0 |
| Celesta | 8 |
| Glockenspiel | 9 |
| Harp | 46 |
| Slow strings | 49 |
| Cello | 42 |
| Choir | 52 |
| Flute | 73 |
| Clarinet | 71 |
| French horn | 60 |
| Warm pad | 89 |

Each MIDI file:
- has one track per instrument and its own channel (channel 10 is skipped);
- sets the tempo and time signature;
- uses soft velocities (pp-mp);
- sends CC7 (volume), CC11 (expression) and CC91 (reverb send);
- uses CC64 sustain pedal on piano and harp.

## Polish pass 0.4.0: status

- **No orchestral render was made.** On 2026-10-11 the machine still had no MuseScore, FluidSynth, SoundFont, ffmpeg or Ogg encoder (checked, see `docs/V2_PROGRESS.md`). All 14 cues are still the **synthesized placeholders**. Nothing in the game or the docs calls them orchestral.
- `MusicManager` now looks in `assets/music/rendered/` first (`<cue>.ogg`, then `<cue>.wav`) and falls back to the placeholder, with **one** warning per run. Dropping rendered files in that folder is enough: no code change is needed.
- `tools/music/render_music.py` automates Steps 2-3 with MuseScore 4. Its processing (seamless loop, loudness, seam check, loop chunk) is unit-tested in `tools/music/tests/`, and the same seam check confirms the current placeholders loop smoothly. **The MuseScore step itself has not been run,** because MuseScore is not installed here.

### Exact steps for the developer (MuseScore 4)

1. Install MuseScore 4 from https://musescore.org (free). Optionally, install Muse Hub sounds and check their licence for a distributed game.
2. Open a terminal in the project folder:
   ```
   python tools/music/render_music.py
   ```
   It finds `C:\Program Files\MuseScore 4\bin\MuseScore4.exe` (or pass `--musescore "path\to\MuseScore4.exe"`). For each cue it renders the MIDI, wraps the reverb tail onto the start of looping cues, normalizes to RMS -22 dBFS with a -1 dBFS peak ceiling, checks the seam, and writes `assets/music/rendered/<cue>.wav`. If `oggenc` is on the PATH it also writes `<cue>.ogg`.
3. Read the printed report. Every looping cue should show `seam_ok: True`. If one does not, listen to it, and adjust it (for example with `--cues name` after changing the instrument mix in MuseScore).
4. If MuseScore adds silence before the first note, the loop drifts. Listen to the first two seconds of a rendered loop. If there is a gap, trim it in an editor, or render that cue from the MuseScore GUI, then run `python tools/music/render_music.py --check`.
5. Open the project in Godot once (to import the files), then run `tools/run_checks.ps1`.
6. Record the sound library (for example "MuseScore 4 MS Basic"), its source and licence in `docs/ASSET_PROVENANCE.md`.
7. Go through the developer listening checklist in `docs/MANUAL_TEST_CHECKLIST.md`.

### Mix (measured, not listened to)

| Layer | Level in the files | Default volume | Effective |
|---|---|---|---|
| Music placeholders | RMS -22.0 dBFS (all 14), peaks -4 to -11 dBFS | 0.5 (-6 dB) | about -28 dBFS RMS |
| Ambience loops | RMS -27.0 dBFS (all 8) | 0.6 (-4.4 dB) | about -31 dBFS RMS |
| Sound effects | peaks 0.05-0.5 (tested: never above 0.5) | **0.7** (was 0.8) | short and soft |
| Footsteps | peaks at most 0.2, plus -6 dB in code | (SFX bus) | very quiet |
| Interface | hover peak at most 0.06 | **0.6** (was 0.7) | barely audible |

The SFX and Interface defaults were lowered a little, so effects sit gently above the music for new players. Existing `settings.cfg` files keep their values. Stingers duck the music by 9 dB over 0.6 s and return over 2 s. These are numbers, not listening, and they need checking by ear (see the checklist).

### Moments (0.4.0)

- **Finale:** the `finale` cue plays for the whole cinematic (about 36 s) and the credits. The `swell` sound marks the moment the light spreads.
- **Rest spots:** sitting plays the soft `swell` sound. The Music bus rises by 2.5 dB and the Ambience bus by 4 dB over 3 s, and they return over about 1.2 s when standing up (`AudioManager.set_rest_boost`). Leaving the world always resets it.
- **Breathe with Lumi** adds no sound of its own. The world's music and ambience continue quietly (the game is paused behind the panel).

## Step 2: render with a real orchestral sound (manual)

Only use a SoundFont or sample library whose licence clearly allows use in a distributed game. Record its name, source and licence in `docs/ASSET_PROVENANCE.md`.

**Option A: MuseScore 4 (free).**
1. Open each `.mid` from `assets/music/midi/`.
2. Assign MuseScore's bundled sounds or Muse Sounds instruments to the tracks.
3. *File > Export > Audio (WAV)*, 48 kHz.
4. Or from the command line: `MuseScore4.exe -o out.wav assets/music/midi/grove.mid`.

**Option B: FluidSynth with a licensed `.sf2`.**
```
fluidsynth -ni -F out.wav -r 48000 YourLicensedFont.sf2 assets/music/midi/grove.mid
```

**Option C: a DAW** (Reaper, LMMS and so on) with free orchestral libraries, for example Spitfire LABS or BBC Symphony Orchestra Discover. **Check each licence yourself.**

## Step 3: post-process

1. Normalize every track to the same loudness. The target is **about -20 LUFS integrated**. The placeholders use **RMS -22 dBFS** as a stand-in, because no loudness meter was available.
2. Keep each loop exactly as long as the score:
   - 8 bars, or 32 beats (24 for the 6/8 coast), at the cue's tempo;
   - to keep the loop seamless, mix the reverb tail back onto the start, as `compose.py` does.
3. Export Ogg Vorbis, 44.1 or 48 kHz, stereo, to `assets/music/ogg/<cue>.ogg`.

## Step 4: integrate in Godot

Since 0.4.0 no code change is needed. Put `<cue>.ogg` or `<cue>.wav` into `assets/music/rendered/`. `MusicManager.music_path()` prefers them and sets looping in code. Pieces without a rendered file keep using their placeholder.

Everything else stays the same:
- crossfades (3 s), and a 2 s hysteresis so border-walking never restarts a track;
- the synchronized meadow layers (`AudioStreamSynchronized`), with day and night layers following the clock;
- stingers that duck the music by 9 dB and then restore it;
- "Continuous music", "Music with quiet pauses" (longer pauses in Gentle mode) and "Music off";
- separate Music and Ambience volumes that persist;
- a safe fallback: missing files log one warning and the original synthesized pad plays.

## Regenerating everything

```
python tools/music/compose.py        # MIDI + placeholder WAVs (about 20 s)
python tools/music/ambience.py       # ambience loops
```
